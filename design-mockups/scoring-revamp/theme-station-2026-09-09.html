What it is today

#golfer-scorecard

Four looks already exist — White, Dark, Glass, Sun — but they are behind two different controls, and neither shows you the options. The moon icon is a cycle: tap it and you get whatever is next (White → Dark → Glass → White). Sun is a separate pill somewhere else on the screen. On the traditional card view there is no light/dark/glass control at all — only Sun.

Start Round — one moon icon, top right. A cycle. No Sun here at all.
Scoring engine / keypad — moon icon + a separate SUN pill, two controls, four options hidden.
Scoring engine / card — SUN pill only. White / Dark / Glass unreachable from this view.

The control

.thm-seg — one segmented rail

A four-up segmented rail, built from tokens already on these screens: the same rounded rail as the Live / Demo / Post Score pills, the same solid-green active state as the F9 / B9 toggle. Every option is visible and one tap away — no cycling, no hunting.

White selected — light rail

Dark selected — dark rail

Rules it keeps

  • 336px wide at 360px — 84px a segment, icon + label, verified on the live app, no clipping.
  • Green #16a34a active, white text. No purple, stock palette, contrast floor held.
  • Sun state uses mass, not size — white ground, 1.5px black frame, weight 800. Mono label width never changes.
  • It replaces today’s moon cycle button and the standalone SUN pill everywhere — net control count goes down, not up.
  • Still one ThemeMode. White/Dark/Glass are the base axis; picking Sun turns Glass off and Glass turns Sun off, exactly as it does now.

One real gap: Sun before you tee off

NEEDS A DECISION

Sun is gated to an active round and every Sun rule is scoped to the scoring engine. So the moment SUN appears on Play Golf and Start Round, tapping it lights the segment but the screen does not change — and a golfer standing in the sun cannot read the setup screen either. Two ways to close it; the second is the honest one.

As it stands — SUN lights up, setup screen unchanged. It is armed for the round, nothing more.
Proposed — the Sun pass extended to the setup card: heavier text, black 1.5px frames, solid green fills, no shadows.

What that costs

  • Widen ThemeMode.sunAvailable() from .round-active to the scorecard tab — the same blast radius Glass already uses.
  • About 20 CSS rules for #scorecardStartSection, mirroring the pass the scoring engine already has.
  • One thing to tune: the course title reflows to two lines at weight 800. Proportional font, so weight does cost width there — it needs a slightly lighter setting than the mono strips do.
